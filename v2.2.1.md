# Ach! v2.2.1 Release Notes

**Release Date:** November 23, 2026  
**Author:** AshraArc  

---

## Highlights

- **Rebrand to Ach! (Archive Chat History):** Unified user-facing naming across the CLI, TUI, installers, skill, and documentation, while keeping `ach` as the primary command.
- **Simpler Dashboard & Help Output:** Replaced noisy uppercase banners with clean `Ach! v2.2.1` / `Ach! · <view>` headers and standard Unix `--help` formatting (`NAME`, `SYNOPSIS`, `DESCRIPTION`, `OPTIONS`, `EXAMPLES`).
- **Repository Rename:** Canonical repository updated to `AshraArc/ach-cli` (the old `-antigravity-chat-manager` URL redirects automatically, and `get.sh` keeps it as a fallback).
- **Docs Refreshed:** Streamlined `README.md` and `docs/index.html` with minimal developer-focused styling and updated install commands.
