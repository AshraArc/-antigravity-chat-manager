# Ach! v2.2.1 Release Notes

**Release Date:** November 23, 2026  
**Author:** AshraArc  

---

## Highlights

- **Rebrand to Ach! (Archive Chat History):** Unified user-facing naming across the CLI, TUI, installers, skill, and documentation, with `ach`, `ach-h`, and `ach-m` as the default installed commands.
- **SQLite WAL + FTS5 Search Engine:** Powered by `history.db` in WAL mode with `sessions_fts` FTS5 full-text indexing across titles, transcripts, and notebooks, alongside `history.lock` (`flock`) concurrency protection.
- **Workspace Transplanting (`ach mv`):** Added `ach mv <id|num> [target_dir]` and `ach mv -g/--group <name> [target_dir]` to move single sessions or entire notebook groups between project directories.
- **Markdown Export (`ach -x`):** Export individual sessions or the entire archive (`ach -x <id|all>`) directly to clean Markdown files in `.agents/exported_chats/`.
- **Simplified TUI & POSIX `--help`:** Replaced noisy uppercase banners with clean `Ach! v2.2.1` / `Ach! · <view>` headers and standard Unix `--help` formatting (`NAME`, `SYNOPSIS`, `DESCRIPTION`, `OPTIONS`, `EXAMPLES`).
- **Repository Migration to `AshraArc/ach-cli`:** Canonical repository updated to `AshraArc/ach-cli` (the previous URL redirects automatically, and `get.sh` retains it as a fallback).
- **Docs Refreshed:** Rewrote `README.md` with Mermaid architecture/execution flowcharts, complete CLI & TUI references, and updated `ach` / `ach-h` / `ach-m` install and usage examples.
