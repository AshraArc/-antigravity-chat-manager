Built for Speed & Developer Control

Everything the native CLI transcript dump was missing.

⚡ Instant Sub-Millisecond Speed

Powered by a lean plain-text TSV master index. Search through hundreds of chat sessions in under a millisecond with zero database overhead.

🔍 1-Key Interactive Resume

Say goodbye to copying 36-character UUIDs. Simply press 1, 2, or use s to jump right back into any session with agy.

🗑️ Batch Cleanup & Pruning

Clean out dead or abandoned chats in bulk with d 1,3,4. Frees up workspace storage and cleans index entries safely with confirmation.

📄 Clean Markdown Export

Convert messy JSONL transcript payloads into readable, formatted Markdown ready for notes, team documentation, or PR summaries.

🛡️ Complete CLI Standards

Includes standard lifecycle flags: --help, --version, --update, and --uninstall right out of the box.

🔄 Self-Healing Recovery

Built-in log repair scans for unindexed sessions and restores damaged or corrupted indexes in seconds without losing transcripts.
