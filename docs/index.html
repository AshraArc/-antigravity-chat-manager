The Honest Difference: Antigravity Built-in vs. sessionList

Antigravity already includes a fast picker (/resume) inside active chats. sessionList doesn't duplicate basic operations—it serves as the dedicated power-user companion for terminal automations and deep management.

Google Antigravity Built-in (/resume)

  • In-chat fuzzy picker for titles
  • Single conversation deletion
  • In-chat conversation renaming
  • Single conversation resume

sessionList Power-User Companion

  • FTS5 Full-Text Search: Searches inside conversation messages and code blocks
  • Multi-Layer Batch Purge: Wipes chats from transcript dirs, conversations/*.db, and central conversation_summaries.db permanently
  • Markdown Note Export: Direct x <num>, x all, and --export for docs & wikis
  • Sequential Folder Selector: Pick CWD, root, or recent projects on [n]
  • Plain Terminal CLI: Run without starting an interactive agy session

Native Antigravity Integration

Built to cooperate directly with Antigravity's internal architecture, not fight it.

🔗 Direct SQLite Sync

Directly queries Antigravity's central conversation_summaries.db. Every chat started in agy is indexed automatically in real time.

🧹 Multi-Layer Purge

Batch deleting in sessionList executes clean SQL deletes across Antigravity's summary & FTS tables. Deleted chats disappear from /resume permanently.

📁 Workspace-Aware Resume

Remembers the original folder where each session started, switching into it before resuming so agy never triggers untrusted folder security prompts.

⚡ Standalone UNIX Pipeline

Run quick queries directly from your shell (ach -l, ach -s, ach -x) without having to launch or wait for the agent LLM runtime.

Engineered for Power Users

Reliable SQLite storage, deep search indexing, and total clean-up controls.

🔍 SQLite WAL + FTS5 Search

Powered by SQLite WAL mode and FTS5 virtual tables. Search deeply through message transcripts, terminal commands, and code blocks—not just titles—from the TUI or --search-cli.

🧹 Complete Multi-Layer Purge

Batch delete sessions with d 1,3,4 or --delete 1,3,4. Purges transcript folders, SQLite databases, and Antigravity's central conversation_summaries.db so chats vanish from /resume forever.

📄 Top-Level Markdown Export

Export any chat with x <num> or all conversations with x all (or CLI flag --export) directly from the top-level table into human-readable Markdown notes.

📂 Sequential Folder Selector

Press [n] to launch a new chat with an intuitive numbered folder picker: [1] CWD, [2] Antigravity Root, recent project workspaces, or [c] custom path.

⌨️ Non-Interactive CLI Flags

Integrate sessionList into shell workflows using ach-h with --search-cli, --export, --delete, --days, and --all without entering interactive menus.

🛡️ Workspace-Aware Resume

Automatically resolves and switches into the original project directory before resuming so agy never halts to ask for untrusted workspace permissions.
