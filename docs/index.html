Engineered for developer flow

Clean primitives that eliminate friction when jumping between tasks and agents.

SQLite WAL + FTS5

Full-text indexed search queries transcript text and user prompts across past sessions in sub-millisecond time.

Interactive & Headless

Use antig-h for instant scripted output or antig-m for an interactive keyboard-driven manager.

Batch Operations

Delete ephemeral or test sessions in bulk using comma or range syntax like d 1,3,4 or d 1-5.

Multi-Workspace Sync

Automatically maps, tags, and transplants conversations across distinct directories without breaking history.

Clean Markdown Export

Dump structured conversation transcripts into human-readable Markdown notes in exported_chats/.

Concurrency Safety

POSIX kernel advisory locking (history.lock) guarantees safe simultaneous access across terminal tabs.

CLI Quick Reference

Shortcuts and flags for everyday terminal use.
