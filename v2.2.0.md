# sessionList v2.2.0 Release Notes

**Release Date:** November 23, 2026  
**Author:** AshraArc  

---

## 🚀 Highlights & Major Features

### 1. SQLite WAL + FTS5 Full-Text Search Engine
- Replaced slow linear scans with SQLite Write-Ahead Logging (WAL) and BM25-ranked full-text indexing (`sessions_fts`).
- Full transcript content is indexed, allowing instant keyword and phrase search via:
  ```bash
  ach -s "search query"
  ```
- Sub-50ms startup latency for all CLI operations.

### 2. Multi-Workspace Project Discovery & Transplant (`ach mv`)
- Seamlessly move/transplant conversations between directories and workspaces without losing session continuity:
  ```bash
  ach mv <id|num> [target_dir]
  ach mv -g, --group <name> [target_dir]
  ```
- Updates both the centralized Antigravity index and local workspace mapping.

### 3. Markdown Batch Export (`ach -x`)
- Export session conversations into clean, formatted Markdown files in `exported_chats/`:
  ```bash
  ach -x all
  ach -x 1
  ```
- Enforces strict boundary checks (`os.path.commonpath`) to prevent directory traversal.

### 4. Hardened `--update` Lifecycle
- Automated fast-forward updating (`git pull --ff-only`).
- Auto-prunes stale aliases (`antig*`, `ag*`), obsolete `.tmp` files, and bytecode `__pycache__` directories.
- Automatically re-generates and checks wrapper executables in `~/.local/bin/`.

### 5. Full Automated Test Harness
- Comprehensive test suite under `tests/` covering core logic, CLI arguments, SQLite WAL & FTS5 engine, and multi-directory transplanting.
- Multi-OS CI workflows for GitHub Actions.
